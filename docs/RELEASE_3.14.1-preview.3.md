# TRELLIS Studio 3.14.1 Preview 3

- Added a native Game Asset pipeline with QuadDC, WTiVo, LOD Tailor, PEC UVs, a baked normal map and multiview UltraTex 2K materials.
- Added a first-stage geometry choice to High Detail and Game Asset.
- Preserved FP32 image conditioning for PiXal3D. Studio runs these workflows with native tensor, mesh and texture components.

Availability depends on the verified local components. See [standalone generation profiles](NATIVE_PROFILES.md).
