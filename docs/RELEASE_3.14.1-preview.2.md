# TRELLIS Studio 3.14.1 Preview 2

- Added a standalone High Detail profile with TRELLIS.2 GGUF, a second geometry pass, QuadDC and MeshLib reconstruction, and 4K PBR textures.
- Added grouped advanced controls for the standalone recipes in Create and the queue editors.
- Preserved completed outputs and reference images from the previous preview. The standard High Detail and Game Asset profiles are available alongside the standalone recipes.
- The standalone Game Asset recipe is visible for inspection while its native sampling and texturing are being ported.

The High Detail preview uses an optional [local GGUF component](NATIVE_PROFILES.md).
