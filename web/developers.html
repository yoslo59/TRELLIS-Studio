02 / MODEL CONTEXT PROTOCOL

Let your agent
work in Studio.

The MCP bridge runs in its own Python environment. It exposes typed tools for models, jobs, collections, rigging, animation, diagnostics, history and export.

STDIO

A client launches the bridge locally. Works with MCP clients that support a process command, including Codex.

Streamable HTTP

Started by Open TRELLIS.cmd. Local clients connect to the running bridge.

03 / ASYNC BY DESIGN

Prepare. Track.
Inspect. Export.

  1. 01

    Upload or find a model

    Use upload_source, list_models and get_model. Uploaded images and models receive source IDs.

  2. 02

    Request the next operation

    Queue generation, create a LOD/game/print copy, or add a rig. Animation edits keep clips on the same model.

  3. 03

    Poll and inspect

    Read progress instead of keeping a tool call open. Use diagnostics and visual review before treating an asset as finished.

  4. 04

    Export for the workflow

    Prepare Blender, Unity, Unreal, GLB, print or collection archives, then download the completed package.
